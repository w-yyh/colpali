## Slide 2｜研究问题：视觉复原不必然等价于检索提升

页面类型：问题定义页。

页面主论断：

前端复原可能改善视觉质量，但未必恢复 ColPali 的排序结构。

页面要点：

- 真实文档退化包括噪声、模糊、JPEG 压缩、低分辨率、几何倾斜与色彩偏移。
- 复原操作可能改善可视质量，也可能改变字符边缘、版面纹理和局部结构。
- ColPali 的 Late Interaction 依赖 query token 与 document patch 的局部匹配。
- 因此需要区分两类收益：视觉质量收益与检索排序收益。

视觉建议：

- 左侧放三段式关系图：`degraded page -> restored page -> retrieval ranking`。
- 右侧放一个简化 patch-token late interaction 示意图。
- 可在底部加小字公式：`Delta nDCG@5 = nDCG@5(restored) - nDCG@5(degraded)`。

可选图片：

- 可使用 `documents/2026.5.20开始/assets/wang_restoration_page001_crop_grid.png` 作为页面底部横向样例。

讲稿：

在传统图像处理任务中，复原效果通常通过图像是否更清晰来判断。但在视觉文档检索中，模型真正关心的是文档语义和版面结构是否更容易被正确匹配。一个去噪或去模糊算法即使提升了主观视觉质量，也可能平滑掉字符细节，或者引入新的伪影，导致 Patch 嵌入分布发生偏移。因此，本部分的核心问题是：前端复原是否能在检索指标上带来稳定收益，以及这种收益在哪些方法上成立。

## Slide 5｜最终结果：轻量复原带来有限但可测的检索收益

页面类型：结果页。

页面主论断：

三种轻量复原方法均带来正向 nDCG@5 增益，但增益远小于 clean-degraded 缺口。

页面表格：

| 输入条件 | nDCG@5 | Recall@5 | MRR | 相对 degraded nDCG@5 |
|---|---:|---:|---:|---:|
| clean baseline | 0.5717 | 0.5829 | 0.6516 | +0.1144 |
| degraded `PD_MB_GN_JC_LR_CS` | 0.4574 | 0.4090 | 0.6251 | 0.0000 |
| gaussian restored | 0.4592 | 0.4072 | 0.6354 | +0.0018 |
| nlmeans restored | 0.4645 | 0.4085 | 0.6821 | +0.0071 |
| wiener restored | 0.4687 | 0.4194 | 0.6490 | +0.0114 |

讲稿：

从最终独立实验可以看到，复合退化使 nDCG@5 从 clean 的 0.5717 降到 0.4574，说明退化显著改变了 ColQwen2 的检索排序。三种轻量复原方法都带来了正向但有限的 nDCG@5 增益，其中 Wiener 滤波达到 0.4687，是 nDCG@5 和 Recall@5 上最好的方法；NLMeans 的 nDCG@5 增益略低，但 MRR 达到 0.6821，说明它更容易把部分 query 的首个相关页面提前。整体来看，复原并没有把性能恢复到 clean 水平，clean 与 degraded 之间仍有约 0.1144 的 nDCG@5 缺口。

## Slide 6｜解耦结论：复原改善输入，但不保证排序结构恢复

页面类型：分析页。

页面主论断：

视觉复原、embedding 修正和检索排序目标是三个不同层次，不能简单等同。

页面要点：

- 前端复原负责改善输入图像，但不直接保证 embedding 排序结构恢复。
- `wiener` 在 nDCG@5 和 Recall@5 上最好，说明频域滤波对复合模糊/压缩退化更有效。
- `nlmeans` 在 MRR 上最好，说明去噪可能改善部分 query 的首个相关结果。
- `gaussian` 的 nDCG@5 略升，但 Recall@5 从 0.4090 降到 0.4072，说明视觉平滑不一定全面改善检索。
- 复原后的最好 nDCG@5 仍只有 0.4687，距离 clean 的 0.5717 仍有明显差距。

视觉资产：

- 可使用 `documents/2026.5.20开始/assets/wang_restoration_page001_full_grid.png` 展示视觉复原样例。
- 页面右侧画三层边界图：
  - image restoration layer
  - embedding / adapter layer
  - retrieval objective layer

讲稿：

这一页的重点是解耦。前端复原确实改善了输入图像，也带来了小幅检索收益，但它并没有完全恢复 ColQwen2 的排序结构。不同方法的指标变化也不一致：Wiener 更适合提升 nDCG@5 和 Recall@5，NLMeans 更适合提升 MRR，而 Gaussian 平滑虽然 nDCG@5 略有提升，但 Recall@5 反而略低于 degraded baseline。这说明复原方法不能只按视觉质量排序，也不能假设“越清晰就越利于检索”。后续 Adapter 或 Patch 加权需要在 embedding 和 score 层进一步处理残留偏移。
